# 学习记录模板

创建或更新 `~/.learn/` 内的文件时使用。花括号是运行时填写的内容，示例不是真实学习记录。已有记录优先保留并补充缺少字段。

## 学习偏好：`profile.md`

```markdown
# 学习偏好
> 创建：{date}
> 更新：{date}

- 当前主题：{topic}
- 当前基础：{已知基础；未知则注明未知}
- 语言：{用户明确指定，或中文默认}
- 讲解方式：{例子、类比、小步骤等；标明用户选择或默认}
- 节奏：一个小知识点、一道问题；等待作答后再继续
- 掌握检查：自己复述或小练习；卡住则换讲法
- 提问界面：优先原生输入框；选择题有选项，复述与练习自由输入
- 已确认偏好：{用户实际确认的内容}

## 观察
{从作答中观察到的倾向；与用户明确选择分开记录}
```

## 主题记录：`topics/{topic-slug}/knowledge-base.md`

```markdown
# {topic} — 学习记录
> 偏好：~/.learn/profile.md
> 创建：{date}

## 概念图

|---|---|---|---|---|---|---|---|---|---|

## 概览
- 已掌握：{数量与概念}
- 发展中：{数量与概念}
- 未解决：{数量与概念}
- 未验证：{数量与概念}
- 到期复习：{概念与日期}

## 接续状态
- 当前知识点：{concept}
- 最后一道题：{完整题目；选择题包含选项}
- 是否待答：{是/否}

- 剩余卡点：{具体误解或前置缺口}
- 下一步：{评价待答题、换讲法、检查迁移或下一个知识点}

## 会话日志
### {date}
- 涉及内容：...
- 已掌握及证据：...
- 尚未解决：...
- 下次起点：...
```

## 领域概念：`topics/{topic-slug}/concepts/{area}.md`

```markdown
# {area} — 概念记录

| 概念 | 理解状态 | 掌握证据 | D | S | 最后复习 | 下次复习 | 稳定度标签 | 评级历史 |
|---|---|---|---|---|---|---|---|---|

## 误解与材料
### {concept}
- 具体误解：{实际回答暴露的问题}
- 更清楚的讲法：{新的例子、类比或前置知识}
- 检查结果：{实际回答与评价}
- 材料来源：{文件与章节、网页地址，或注明一般知识}
```

## 字段规则

- 理解状态：已掌握、发展中、未解决、未验证。以实际复述或练习证据判断，不能用复习稳定度代替。
- D、S、稳定度标签和评级历史：按 `fsrs.md`，无可靠评价时留空或写未评级。
- 主题与领域路径：小写英文、数字和连字符，例如 `python-basics/functions`、`ai-isp/raw-images`。
- 日期：`YYYY-MM-DD`，按用户已知时区；文档正文使用本轮选定的教学语言。
- 待答状态：提问前先保存；只有收到实际回答后才修改评价与评级。
