# 简化复习安排（参考 FSRS 思路）

来源思路：[Free Spaced Repetition Scheduler](https://github.com/open-spaced-repetition)。本文件继承并整理上游的简化倍率方案，**不是完整 FSRS 实现**，没有经过用户数据拟合。数值只用于会话中的复习建议，不承诺记忆概率或不会遗忘。

## 回答评级

| 评级 | 依据 |
|---|---|
| Again / 1 | 忘记核心意思，或存在根本误解 |
| Hard / 2 | 核心意思接近，但有缺口或明显困难 |
| Good / 3 | 成功复述或完成需要理解的练习 |
| Easy / 4 | 清楚、熟练地复述并能迁移应用 |

评级依据答案内容，不能根据回复快慢推断信心。猜对选择题但缺少理由时先记录“待验证”，检查理解后再评级。

## 初次评级

| 评级 | 初始难度 D | 初始稳定度 S（天） |
|---|---|---|
| 1 | 7.0 | 0.4 |
| 2 | 6.0 | 0.9 |
| 3 | 5.0 | 2.4 |
| 4 | 3.0 | 5.8 |

D 是 1–10 的难度估计。S 是复习间隔的启发式尺度，不是经过测量的保留时间。

## 后续评级

令旧值为 D、S，回答评级为 rating：

```text
D_new = clamp(D - 0.28 * (rating - 3), 1, 10)

base_multiplier:
  rating 1 -> 0.3
  rating 2 -> 1.2
  rating 3 -> 2.5
  rating 4 -> 3.0

adjustment = 0.7 + 0.06 * (11 - D_new)
S_new = max(0.4, S * base_multiplier * adjustment)
```

难度和稳定度可以保留两位小数。每次有可靠作答证据才追加评级并更新数值；待答题不更新。

## 复习日期

本技能按天保存日期，不安排小时级提醒：

```text
interval_days = max(1, floor(S_new + 0.5))
next_review = 当前日期 + interval_days
```

初次评级用初始 S 代替 S_new。采用用户提供的时区；未知时用当前环境日期。当天答错先补讲，后续复习最早放在次日。

## 多个概念到期

优先看尚未解决的误解，再考虑到期且间隔短的概念。仍然一次一个知识点、一题一答；用户有明确会话目标时按其目标进行。

## 稳定度标签与理解状态

| 稳定度标签 | S 范围 |
|---|---|
| 待频繁复习 | S < 3 |
| 逐步稳定 | 3 ≤ S < 14 |
| 较稳定 | 14 ≤ S < 90 |
| 长间隔复习 | S ≥ 90 |
| 未评级 | 没有可靠评级 |

长间隔概念仍保留 next_review。另行保存理解状态（已掌握、发展中、未解决、未验证）与证据；决定是否继续下一知识点时看这些证据，不看 S 或标签。
